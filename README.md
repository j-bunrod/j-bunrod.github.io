# 🌐 j-bunrod.github.io

หน้าเว็บส่วนตัวของ **j-bunrod** — ธีมดำ + gradient ม่วง→ฟ้า + เรืองแสง neon (cyberpunk)

🔗 **เว็บไซต์:** https://j-bunrod.github.io

---

## 📦 โครงสร้าง

```
j-bunrod.github.io/
├── index.html   # โครงหน้า (hero / เกี่ยวกับ / ติดต่อ / ฟุตเตอร์)
├── style.css    # ธีม dark + neon + responsive
├── script.js    # typewriter, scroll reveal, copy link, เมนูมือถือ
├── README.md
└── TASKS.md
```

## 🛠️ รันดูในเครื่อง

```bash
cd ~/bunrod-labs/j-bunrod.github.io
python3 -m http.server 8080
# เปิด http://localhost:8080
```

## 🚀 Deploy

Push ขึ้น `main` แล้วเปิด **Settings → Pages → Deploy from a branch → `main` / `root`**
→ เว็บจะขึ้นที่ https://j-bunrod.github.io

## 📱 ดีไซน์

- **mobile-first** — base style คือมือถือ, breakpoint เดียวที่ `768px`
- ไม่มี dependency / ไม่มี build step — เปิดไฟล์ได้เลย
- รองรับ `prefers-reduced-motion`
- ฟอนต์: Orbitron (display) + Noto Sans Thai (body)
